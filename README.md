# LightGBM pipeline

Project data is organized into three folders:

- `Raw_DATASET/` contains the input CSV files.
- `pre_processing/` contains shared feature cleaning and transformation pipeline.
- `data_split/` is generated by the pipeline and contains `train/`, `validation/`, and `test/` CSVs.

Run `main.py` to split each raw CSV into 70% training, 15% validation, and 15% test rows, stratified by `label`. The preprocessing medians, category mappings, and scaler are fitted on training rows only; those same transformations are applied to validation and test. The processed splits are written to `data_split/`, then the LightGBM training stage runs with five training folds. It does not calculate evaluation metrics or write model artifacts.

The pipeline prints short progress messages for splitting, preprocessing, and model training.

```powershell
.venv/Scripts/python.exe -B main.py
```
